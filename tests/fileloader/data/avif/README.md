# AVIF fixtures

`red.avif` is a generated 12 by 8 red still image (no external artwork).
It was created with FFmpeg's libaom encoder:

```sh
ffmpeg -f lavfi -i color=c=red:s=12x8 -frames:v 1 -c:v libaom-av1 -still-picture 1 -crf 0 red.avif
```

`images.zip` contains the same bytes as `001.avif` and `002.AVIF`, plus
`notes.txt`, to exercise archive filtering and extraction.

`animated.avif` contains two 12 by 8 frames, red followed by green, at two
frames per second. It exercises first-frame-only AVIF display and corrupt
sequence payloads. It was generated by sending these RGB24 frames to:

```sh
ffmpeg -f rawvideo -pixel_format rgb24 -video_size 12x8 -framerate 2 -i pipe:0 -frames:v 2 -c:v libaom-av1 -crf 0 -cpu-used 6 -f avif animated.avif
```
